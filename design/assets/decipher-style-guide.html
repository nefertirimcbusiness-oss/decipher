Typography

Font families and type scale for headings, body text, UI labels, and decorative elements.

Font Families

--font-headingPlayfair Display — For headings
--font-bodyQuicksand — For body text, clean and warm
--font-uiNunito — For buttons, labels, UI elements
--font-handwrittenDancing Script — For scrapbook headings, quotes
--font-monoIBM Plex Mono — For timestamps, code

Type Scale

--text-h1 / 2.25rem Playfair Display 700Hero Heading
--text-h2 / 1.75rem Playfair Display 600Section Heading
--text-h3 / 1.375rem Quicksand 600Card Title
--text-body / 0.9375rem Quicksand 400Regular body text for reading comfort. This is the default size for all paragraph content throughout the app. Generous line height for readability.
--text-caption / 0.75rem Nunito 500Small labels, timestamps, metadata
